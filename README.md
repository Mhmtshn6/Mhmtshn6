### 👨‍💻 Hakkımda
Donanımdan ziyade tamamen **saf yazılım, backend mimarileri ve DevOps** süreçlerine odaklanan, temiz mimari (Clean Architecture) prensiplerini benimsemiş bir mühendisim. Ölçeklenebilir ticari platformlar, güçlü API servisleri, mobil uygulamalar ve makine öğrenmesi odaklı sistemler geliştirmekten keyif alıyorum.

- 🔭 **Odak Noktam:** Canlıya alınan projelerde yüksek performanslı backend servisleri kurgulamak.
- 🌱 **Derinleştiğim Alanlar:** Docker, IIS Deployment, ASP.NET Core mimarileri ve Makine Öğrenmesi.
- 💡 **Mottom:** Karmaşık problemleri, SOLID prensiplerine sadık kalarak sade ve sürdürülebilir kod yapılarıyla çözmek.
